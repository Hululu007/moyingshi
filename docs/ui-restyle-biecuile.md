## 8. 风险与回退

- **设置页丢行**：重组最大风险。防法：实施前先拉一张“现有全部设置行 → 新分组”逐行对照表（以 `Setting*Fragment` 9 页 + strings 为准），改完逐行勾；每行跳转目标不变，只换行皮。
- **首页吸顶被撞坏**：首页最后动；改完第一件事复核吸顶（上滑钉住、下滑回位、背景不透明、点分类仍切换）。
- **深色模式**：每屏改完都要对一遍深色模式（卡片底色、文字、分隔线、当前值），不能只验浅色。
- **图标风格不统一**：新画图标先画 3 个样稿对一遍（圆底色 + glyph 粗细 + 同框），定了再批量画，避免返工。
- **回退**：每屏只改外观不改功能，出问题回滚单屏提交即可（每屏一提交 + recovery tag）；功能逻辑零改动，回滚不丢数据。
- **验证**：本机无 SDK，编译检查靠推后 GitHub 构建；每屏推上去编测试版后按该屏清单真机验（设置页重点验行跳转一个不少、开关状态一致；详情页验演员/推荐/换源；播放器验控制栏与画面按钮；首页验吸顶 + 轮播 + 继续观看）。
